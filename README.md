# Lab-estudio-sueno

# Laboratorio 2: Clasificación de Estrés y Despliegue Web

##  Resumen del Proyecto

Este proyecto es la continuación directa del **Análisis de Datos (Tarea 2)** sobre el *dataset* de Patrones de Sueño y Estilo de Vida. El objetivo principal fue desarrollar, entrenar y evaluar múltiples **modelos de clasificación** para predecir la variable objetivo binaria del nivel de estrés (`ESTRES MODERADO` vs. `ESTRESADO`).

La fase culminante del laboratorio fue la **creación de una Interfaz de Usuario (UI)** mediante **[Gradio/Streamlit]** para permitir que el modelo sea consumido de manera interactiva, logrando un despliegue básico del sistema de clasificación.

###  Objetivos de la Clasificación

* **Variable Objetivo:** `Nivel_Estres_Binario` (preparada en la Tarea 2).
* **Finalidad:** Predecir si un individuo se encuentra en la categoría de **ESTRESADO** o **ESTRÉS MODERADO** basándose en sus hábitos de vida (sueño, ejercicio, ocupación, etc.).
